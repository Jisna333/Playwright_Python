# Python Milestone Assessment

## Overview
This repository contains solutions for the Python Milestone Assessment covering two questions:
1. Student Marks Management System
2. Employee File Management System

## Questions Included

### Question 1: Student Marks Management System
- Accept details of multiple students
- Calculate total, average, grade, and result
- Display student information in formatted way
- Location:`question1/main.py`

### Question 2: Employee File Management System
- Manage employee information using files
- Read/write employee data
- Generate reports on employee salaries and roles
- Location:`question2/main.py`

## How to Run

### Question 1
cd question1
python main.py


### Question 2

cd question2
python main.py
